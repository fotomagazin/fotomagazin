# Фотомагазин

**Фоторедактор со слоями прямо в браузере.** Один файл — без установки и регистрации.
Слои и маски, Camera Raw, кадрирование, выделение, текст, штамп, кисть и ластик.

🌐 Сайт: https://fotomagazin.github.io
⬇️ Скачать: [последняя версия](https://github.com/fotomagazin/fotomagazin/releases/latest/download/fotomagazin.html)

> Это **бета-версия 0.1**: основа работает, но программа ещё развивается.
> Идеи и ошибки — в Telegram-бот [@fotomagazin_bot](https://t.me/fotomagazin_bot),
> новости и опросы — в канале [@fotomag_app](https://t.me/fotomag_app).

## Как запустить

1. Скачайте `fotomagazin.html`.
2. Откройте его двойным кликом — программа запустится в браузере (лучше всего в Chrome или Edge).
3. Перетащите фото в окно.

## Что в репозитории

- `fotomagazin.html` — сама программа (HTML + CSS + JavaScript в одном файле).
- `bot/` — сервер бота обратной связи (Cloudflare Worker): принимает отзывы из формы и сообщения в Telegram и пересылает их автору.
- `brand/` — логотип.
