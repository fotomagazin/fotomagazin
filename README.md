# Фотомагазин

**Фоторедактор со слоями прямо в браузере.** Один файл — без установки и регистрации.
Стили в один клик, кривые, слои и маски с режимами наложения, свет и цвет (экспозиция, температура, тени, насыщенность), резкость, размытие, виньетка и зерно, кадрирование, выделение, текст, штамп, кисть и ластик. Сохранение в JPG, PNG и WebP нужного размера.

🌐 Сайт: https://fotomagazin.github.io
⬇️ Скачать: [последняя версия](https://github.com/fotomagazin/fotomagazin/releases/latest/download/fotomagazin.zip) (архив: программа + инструкция «Как пользоваться»)

## Как запустить

1. Скачайте архив и распакуйте его — получится папка «Фотомагазин».
2. Откройте в ней `fotomagazin.html` двойным кликом — программа запустится в браузере (лучше всего в Chrome или Edge).
3. Перетащите фото в окно.

## Что в репозитории

- `app/fotomagazin.html` — сама программа (HTML + CSS + JavaScript в одном файле).
- `app/Как пользоваться.txt` — инструкция, которая кладётся в архив вместе с программой.
- `tools/` — служебные скрипты: сборка архива для скачивания, скриншоты для сайта.
- `bot/` — сервер бота обратной связи (Cloudflare Worker): принимает отзывы из формы и сообщения в Telegram и пересылает их автору.
- `brand/` — логотип.
